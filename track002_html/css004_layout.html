1. block vs inline

block
width O, 줄바꿈 O
inline
width X, 줄바꿈 X

2. 배치

  • float : 왼쪽 or 오른쪽 옆에 붙이기 (끊기 clear-both)
  • position : 정확한 자리를 정해서 붙이기 (좌표)
  • display : 블록에 줄서기, 속성 바꾸기

3. 배치(1) - float

Left(왼쪽) 줄바꿈 안됨 - inline

Right(오른쪽) 줄바꿈 안됨 - inline

float 속성 끊기 - clear: both; / overflow: hidden;

4. 배치(2) - position - relative(누구 안에) + absolute(좌표)

WHERE I AM

종류 : static(기본값), relative(박스 위치o), absolute(박스 위치x), fixed(브라우저 고정), sticky(스크롤 할 때 특정지점에 붙기)

부모 : relative(공간 확보) / 자식 : absolute(원하는 위치 배치) - 좌표

5. 배치(3) - display

속성 바꾸기 : display:block, inline, inline-block, none

배치 - 박스들이 어떻게 놓일지 정하는 규칙 (정리 도우미) display:flex
