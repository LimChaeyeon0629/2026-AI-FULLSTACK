# 🚀 임채연 | 사용자 화면부터 DB 저장까지 연결하는 풀스택 개발자

> 완벽보다 완성을.
> **기획부터 배포까지, 사용자 흐름과 데이터 흐름을 끝까지 연결하는 개발자입니다.**

**화면에서 발생한 요청이 API와 서비스 로직을 거쳐

데이터 정합성, 중복 처리, 권한 검증, 비동기 처리와 실제 배포 환경까지 경험했습니다.
