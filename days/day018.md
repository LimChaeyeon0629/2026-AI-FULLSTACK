1. OOP?
Object Oriented Programming 객체 지향 프로그램 (틀 기반 프로그램)

2. OOP특징 
캡다상추 (캡슐화, 다형성, 상속, 추상화)
캡슐화: private 외부 접근 금지
다형성: 한 가지 타입으로 여러 타입 관리, 확장성
상속: 부모 클래스의 재사용
추상화: 핵심 기능을 추출해서 만든 모델링

3. 클래스는 ( 멤버 변수 )와 ( 멤버 함수 )를 갖는다 

4. 클래스와 인스턴스 구분
- 클래스는 ( 붕어빵 찍어내는 틀 )
- 인스턴스는 ( 만들어진 붕어빵 ) → 인스턴스화 붕어빵 만들기
